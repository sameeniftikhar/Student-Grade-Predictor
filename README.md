# 🎓 Student Grade & CGPA Predictor 

A robust **C++ console application** built during my 1st semester of BSSE at GCUF. This tool calculates accurate semester GPA/CGPA based on credit hours and percentage marks, while acting as an automated academic advisor to predict future grade pathways.

---

## 🚀 Why This Project Matters
This project isn't just a basic classroom exercise. It was engineered by applying modern industry practices, blending core **C++ development** with foundational frameworks from my **Agile Project Management** and **Artificial Intelligence (AI)** certifications.

---

## ⚡ Core Features
* **Accurate GPA Math:** Multiplies absolute Grade Points by course Credit Hours to ensure accurate university-standard grading calculations.
* **If-Else Grading Scale:** Uses standard GCUF brackets to map percentage inputs directly to corresponding GPA scales (e.g., 85%+ = 4.0).
* **Predictive Academic Counseling:** Features an algorithmic advisory logic block that analyzes the final GPA and prints strategic advice to help students improve or maintain their academic standing.
